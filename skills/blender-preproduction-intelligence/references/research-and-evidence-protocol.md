# Research and evidence protocol

## Source record

For every source actually inspected, record:

| Field | Meaning |
|---|---|
| ID | Stable local reference such as SRC-01 |
| Title | Exact page/document title |
| Publisher | Manufacturer, institution, publication, etc. |
| URL | Exact URL actually opened |
| Date/version | Publication date or model/software revision |
| Supports | Exact claims/features supported |
| Limitations | Variant mismatch, missing units, perspective, marketing-only, etc. |
| Confidence | High / Medium / Low |

## Claim ledger

| Claim | Status | Source IDs / user evidence | Confidence | Notes |
|---|---|---|---|---|
| Exact overall length | SOURCE-VERIFIED | SRC-01 | High | Verify whether mirrors excluded |
| Rear diffuser internal shape | UNKNOWN | — | Unknown | No underside reference |

## Search query patterns

- Exact model + generation + year + official dimensions
- Exact model + press kit + technical specifications
- Exact model + technical drawing + side/front/top
- Exact building + architect + elevation/section drawings
- Exact machine + service manual + exploded view
- Exact product + teardown + internal assembly

Use exact model/variant terms. Avoid broad searches that mix generations.

## Evidence rules

- Search snippets are leads, not inspected evidence.
- Search result thumbnails are not dimensional proof.
- A marketing render may be retouched or depict a concept, not a production version.
- A fan recreation may be useful for visual ideas but is not authoritative.
- Never copy a dimension from a different trim/year without a clear caveat.
- Record contradictory facts; do not silently choose whichever is convenient.
