# Blender Visual Reference Intelligence

Skill 02 for the Blender MCP skill system.

## Install
Copy the `blender-visual-reference-intelligence` folder into the skills directory used by your agent. Keep the `references/` and `templates/` folders beside `SKILL.md`.

## Use
Activate for image-based 3D reconstruction, multi-view interpretation, reference matching, component identification, proportion analysis, or visual QA against reference images.

## Boundaries
This skill is read-only. It does not execute Blender modelling commands or certify mesh topology. It prepares a traceable visual evidence package for Blender Artist Workflow and Blender Geometry Engineering.

## Files
- `SKILL.md` — activation, workflow, evidence rules, output contract, integration.
- `references/visual-reference-analysis-playbook.md` — detailed operational procedures and failure patterns.
- `templates/visual-reference-analysis-report.md` — reusable analysis report.
