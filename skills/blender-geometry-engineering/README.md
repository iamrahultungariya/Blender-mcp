# Blender Geometry Engineering — Skill 03

Geometry-first engineering and verification for Blender MCP workflows.

## Package contents
- `SKILL.md` — core skill and operating contract.
- `references/geometry-engineering-playbook.md` — construction, topology, vehicle checks, failure diagnosis and audit safeguards.
- `templates/geometry-engineering-report.md` — reusable evidence-based report.

## Skill chain
1. `blender-preproduction-intelligence` — WHAT to build and under which constraints.
2. `blender-visual-reference-intelligence` — WHAT visual evidence supports.
3. `blender-geometry-engineering` — HOW to construct and verify geometry.
4. `blender-artist-workflow` — coordinates wider asset production and delivery.

Architecture findings from the supplied MCP v2.2.7 audit are treated as verification targets, not proof that the installed runtime is unchanged.

## Installation
Copy the complete `blender-geometry-engineering-v2` folder into the agent's skills directory. Preserve the `references/` and `templates/` subfolders.
